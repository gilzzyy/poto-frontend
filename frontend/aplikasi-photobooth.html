Pasang sebagai aplikasi

Photobooth Asyricame adalah PWA — bisa dipasang ke layar utama HP/laptop dan dibuka seperti aplikasi biasa.

Browser ini belum menyediakan prompt instal otomatis. Pasang manual lewat menu browser: ⋮ → “Instal aplikasi” / “Tambahkan ke Layar Utama”.

Catatan: instalasi penuh (prompt instal & mode offline) aktif setelah situs ini dideploy ke HTTPS; di pratinjau ini tombolnya menyiapkan prompt bila browser menyediakannya.
